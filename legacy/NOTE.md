# Legacy files (superseded)

`Risk_Management_and_Var_es_engine_for_stocks.ipynb` and `README_original.md` are the original notebook and README, kept so that the audit in `AUDIT.md` and `CLAIMS.md` can be checked against the code it describes (cell and line references there point to this notebook).

They are not maintained, and they contain the defects and unsupported claims listed in `AUDIT.md`. The notebook will also fail on current pandas. Use the `riskengine/` package and the root `README.md` instead.
