# Module test matrix

One row per module or entry point. A test is cited by its function name; every name below is checked by
`test_every_test_named_in_the_documents_exists`, so a renamed or deleted test cannot leave a dangling citation.

Status values: **PASS** (every listed behaviour is exercised and the tests passed in the final runs recorded in
`ALL_MODULES_VALIDATION.md`), **FAIL**, **BLOCKED** (cannot be run in this environment without breaking a standing
rule, for example by using the network), **NOT APPLICABLE** (the feature does not exist). No row is FAIL.

"Independent reference" means a calculation that does not call the code under test: a hand computation, a plain-loop
reimplementation in the test, `scipy.stats` or `statistics.NormalDist`, or a closed form.

The unit tests use hand-constructed deterministic fixtures (`tests/unit/fixtures.py`, no random numbers). The
integration tests use the frozen real-price snapshot in `data/`. Random numbers appear only in `tests/statistical`,
which is labelled synthetic and never writes to `data/` or `results/`.
